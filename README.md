## Corrections in v23

The Most Holy Rosary is appointed October 7, 2026. October 4 is the Nineteenth Sunday after Pentecost. Obsolete Rosary commemorations before the corrected feast date have been removed. Saint Francis is appointed October 10.

Under the user-approved hybrid calendar, simple octave days receive commemorations rather than independent Offices. October 6 is Saint Bruno, III Class, with a commemoration of Saint Michael's octave day. Monday evening October 5 is First Vespers of Bruno. III Class feasts have First Vespers only; I and II Class feasts retain First and Second Vespers. The III Class ordinary Office uses weekday psalmody unless a Proper explicitly provides otherwise.

Historical Cormier classifications remain source evidence. They do not override these adopted hybrid policies. The annual Ordo and breviary website use the same calendar engine and registers.

October 30 Holy Relics remains the II Class principal feast. The restored name now resolves to the same observance, removing its duplicate commemoration. This identity correction also applies to the local 2027 draft. Only the October 30 event is revised in each published feed; all existing event identifiers and late-2026 coverage remain intact.
